Movement System - Level 1

Voor level 1 heb ik een 2D movement systeem ontwikkeld met behulp van Rigidbody2D physics. De speler beweegt horizontaal via input en kan springen met een ground check gebaseerd op Physics2D.OverlapCircle. Daarnaast heb ik een double jump mechaniek toegevoegd via een extraJumpValue. Ik heb bewust gekozen voor een physics-based aanpak in plaats van transform-beweging, zodat botsingen en interacties stabiel en realistisch blijven. Alle belangrijke waarden zoals moveSpeed en jumpForce zijn instelbaar in de Inspector, zodat het systeem flexibel blijft.

private void FixedUpdate()
{

        MoveInput * moveSpeed,

}
PlayerJump.cs — Jump & Ground Check 
private void Update()
{
    if (isGrounded)
    {
        extraJumps = extraJumpValue;
    }

    if (Input.GetKeyDown(keyboardJumpKey) || Input.GetKeyDown(arcadeJumpKey))
    {
        if (isGrounded || extraJumps > 0)
        {
            rb.linearVelocity = new Vector2(
                rb.linearVelocity.x,
                jumpForce
            );

            if (!isGrounded)
            {
                extraJumps--;
            }
        }
    }
}

private void FixedUpdate()
{
    isGrounded = Physics2D.OverlapCircle(
        groundCheck.position,
        groundRadius,
        groundLayer
    );
}

Enemy Behaviour - Level 1

Voor Level 1 heb ik een enemy-systeem ontwikkeld waarbij vijanden automatisch tussen verschillende waypoints bewegen. Met Vector2.MoveTowards bewegen de enemies tussen deze punten. Daarnaast heb ik een detectiesysteem toegevoegd dat de afstand tussen de enemy en de speler controleert. Wanneer de speler dichtbij genoeg komt, begint de enemy hem te achtervolgen. Als de speler binnen de attack range komt, wordt de attack-status geactiveerd. Door gebruik te maken van verschillende ranges kan ik eenvoudig bepalen wanneer een enemy patrouilleert, achtervolgt of in de aanvalstatus komt.

Codefragmenten

EnemyWalk.cs — Enemy Detection 
protected override void EnemyBehaviour()
{
    float distance = Vector2.Distance(
        transform.position,
        player.position
    );

    isChasing = false;
    isAttacking = false;

    if (distance <= attackRange)
    {
        isChasing = true;
        isAttacking = true;
    }
    else if (distance <= chaseRange)
    {
        isChasing = true;
        Chase();
    }
    else
    {
        Patrol();
    }
}
EnemyWalk.cs — Patrol & Chase 
private void Patrol()
{
    if (waypoints.Length < 2) return;

    Transform target = waypoints[currentIndex];

    transform.position = Vector2.MoveTowards(
        transform.position,
        target.position,
        patrolSpeed * Time.deltaTime
    );

    if (Vector2.Distance(transform.position, target.position) < 0.05f)
    {
        if (currentIndex == waypoints.Length - 1)
            direction = -1;
        else if (currentIndex == 0)
            direction = 1;

        currentIndex += direction;
    }
}

private void Chase()
{
    transform.position = Vector2.MoveTowards(
        transform.position,
        player.position,
        chaseSpeed * Time.deltaTime
    );
}

Coins - Level 1

Voor Level 1 heb ik een coin-systeem gemaakt waarmee de speler coins kan verzamelen. Met OnTriggerEnter2D controleer ik of de speler een coin raakt. Wanneer dit gebeurt, wordt het aantal coins verhoogd, een geluid afgespeeld en de coin verwijderd. Daarnaast heb ik met TextMeshPro een UI-counter gemaakt die het aantal verzamelde coins op het scherm bijwerkt. Hierdoor kan de speler tijdens het spelen zien hoeveel coins hij heeft verzameld.

Codefragmenten

Coin.cs — Coin Collection 
private void OnTriggerEnter2D(Collider2D collision)
{
    if (collision.CompareTag("Player"))
    {
        PlayerMovement playerCoin =
            collision.GetComponent<PlayerMovement>();

        if (playerCoin != null)
        {
            playerCoin.coins++;

            if (AudioManager.audioCurrent != null && coinClip != null)
            {
                AudioManager.audioCurrent.PlaySound(coinClip);
            }

            Destroy(gameObject);
        }
    }
}
CoinCounterUI.cs — UI Update 
[SerializeField] private PlayerMovement playerCoin;
[SerializeField] private TextMeshProUGUI coinText;

[SerializeField] private string labelName = "coins";

private void Update()
{
    coinText.text = labelName + ": " + playerCoin.coins;
}

Healthbar - Level 1

Voor Level 1 heb ik een health-systeem gemaakt waarmee de speler schade kan krijgen en levens kan verliezen. Met PlayerHealth houd ik bij hoeveel HP de speler heeft. Wanneer de speler schade krijgt, wordt de HP verlaagd. Daarnaast heb ik met Unity UI en TextMeshPro een healthbar gemaakt. De balk wordt aangepast aan de huidige HP en toont hoeveel levens de speler nog over heeft.

Codefragmenten

PlayerHealth.cs — Health & Damage 
private void Start()
{
    currentHealth = maxHealth;
    healthbar.SetMaxHealth(maxHealth);
}

public void TakeDamage(int amount)
{
    if (isDead) return;

    if (shieldActive)
        amount /= 2;

    currentHealth -= amount;

    healthbar.SetHealth(currentHealth);

    if (currentHealth <= 0)
    {
        Die();
    }
}
HealthbarUI.cs — Healthbar Update 
private void Update()
{
    float current = playerHealth.CurrentHealth;
    float max = playerHealth.MaxHealth;

    fillImage.fillAmount = current / max;

    healthText.text = current + " / " + max;
}
